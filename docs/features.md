## Features

*   **Interactive Color Selection:** A visual interface (e.g., a color wheel or sliders) to pick any color.
*   **Color Value Display:** Real-time display of the selected color's Hex and RGB values.
*   **Copy to Clipboard:** Functionality to easily copy the Hex or RGB values.
*   **Save Color:** (Optional) Ability to save selected colors to a personal palette.
*   **View Saved Colors:** (Optional) A dedicated page to browse and manage saved colors.
