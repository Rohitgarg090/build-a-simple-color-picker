## User Stories

*   As a user, I want to be able to visually select any color so that I can find the exact shade I need.
*   As a user, I want to see the Hex and RGB values of the color I've selected so that I can use it in my projects.
*   As a user, I want to be able to copy the color values to my clipboard with a single click so that I can quickly paste them elsewhere.
*   As a user, I want to be able to save colors I like so that I can refer to them later.
*   As a user, I want to be able to view all my saved colors in one place so that I can easily manage my color palettes.
